# Reusable modules

A module adds behavior that multiple coins can use with their own settings. Its source, configuration, permissions and management actions form one reviewed version.

Every coin records the module versions selected at launch. Publishing a newer version does not replace the code in existing coins.

Modules can earn the fee share recorded by their host and launch. Foundation allocates module rewards from the creator fee; earlier hosts have different rules. Earnings depend on use and trading activity, not publication alone.

[Fees by contract version](../reference/fee-versions.md) explains the reward models.
