# Create

For a coin configured on the website, follow [Launch a coin](launch.md). Module Mode creates the coin and pool, with a first buy and any selected modules, in one wallet transaction.

For a project with its own contracts, follow the [Custom Launch quickstart](../developers/custom-launch-quickstart.md). The API prepares the launch; the controller wallet signs it.

Module authors can use [Build a module](../developers/module-mode.md) to understand the host interfaces, review process and submission status.
