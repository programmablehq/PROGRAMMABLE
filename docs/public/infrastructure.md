# How Programmable works

The website or API prepares a transaction for the launching wallet. The wallet reviews and signs it. After the transaction succeeds, the index verifies the launch record and publishes the coin's identity.

Module Mode uses a factory to create the token, pool and selected modules. The website's first buy runs in the same transaction. Custom Launch packages a project's source and deployment plan, checks the requirements of its API profile and records execution through a Launch Stamp Router.

A coin is identified by its chain and contract address. The source record identifies the launcher and version used to create it. Price, liquidity, charts and external trading support are added separately.

[Verify a launch](developers/verify.md) covers provenance checks. [Index launches](developers/indexing.md) explains how to publish verified records without depending on optional market data.
