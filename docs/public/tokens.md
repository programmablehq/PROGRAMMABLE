# Launch models

| Model | Use it for | Guide |
| --- | --- | --- |
| Module Mode | A coin configured on the website, with a Uniswap v4 pool and compatible modules | [Module Mode](models/module-mode.md) |
| Custom Launch | A token, hook or application with its own source and deployment plan | [Custom hooks](models/custom.md) |
| Classic on Ethereum | Reference for existing fixed supply Ethereum coins | [Classic](models/classic.md) |

Module Mode and Custom Launch use different deployment and verification interfaces. Both leave the launch transaction with the controller wallet. The selected contract determines the fees, liquidity and actions available after launch.
